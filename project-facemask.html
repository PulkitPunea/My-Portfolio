Overview
A standalone Python desktop application for real-time face mask detection via webcam, with a live GUI and detection analytics. Integrates a trained YOLOv8m model with OpenCV for frame-by-frame inference using threaded camera capture to avoid UI blocking. Built with a CustomTkinter GUI showing a live camera feed, start/stop controls, real-time detection counter, and FPS overlay. Packaged as a standalone executable using PyInstaller with bundled model weights — demonstrating end-to-end application shipping experience.
Tech Stack
Python YOLOv8m (Ultralytics) OpenCV Threading CustomTkinter PyInstaller Git · GitHub
Key Features
⚡
Real-time Inference Pipeline
YOLOv8m model integrated with OpenCV for live frame-by-frame detection. Threaded camera capture ensures inference never blocks the UI, maintaining smooth FPS.
🖥️
Desktop GUI
CustomTkinter GUI with live camera feed display, start/stop controls, real-time detection counter, FPS overlay, and correct aspect ratio padding.
📦
Standalone Executable
Packaged with PyInstaller — bundled model weights (best.pt) and icon into a single .exe. No Python installation required to run.
🎯
Performance Tuning
Inference optimised for real-time FPS on consumer hardware — same performance-critical thinking directly applicable to game AI and character detection in UE4.
