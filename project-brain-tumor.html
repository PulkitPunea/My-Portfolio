Overview
A medical imaging system that localises brain tumors in MRI scans using the lightweight YOLOv8n (nano) architecture. Trained on annotated MRI datasets using the Ultralytics YOLO CLI (task=detect, imgsz=640) — the nano variant was chosen specifically for real-time inference speed on resource-constrained hardware, balancing accuracy against latency. The project is structured with separate data, scripts, and runs/detect directories with tracked model outputs, demonstrating disciplined ML experiment management.
Tech Stack
Python YOLOv8n (Ultralytics) YOLO CLI (task=detect) NumPy MRI Dataset Annotation Experiment Management Git · GitHub
Key Features
🎯
Tumor Localisation
Object detection trained on annotated MRI scans — outputs bounding boxes around tumor regions for rapid diagnostic screening assistance.
⚡
Nano Model for Speed
YOLOv8n chosen deliberately over larger variants — the nano architecture trades marginal accuracy for significantly faster inference on resource-constrained hardware, enabling real-time deployment.
🗂️
Disciplined ML Structure
Separate data, scripts, and runs/detect directories with tracked model outputs — clean experiment management for reproducible training runs.
🔬
Performance-critical Mindset
Optimising inference pipelines for latency-sensitive, constrained hardware — the same thinking applied to game AI and runtime systems in Unreal Engine.
