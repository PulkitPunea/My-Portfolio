Overview
Super Car Driving Simulator is a live Android game on Google Play with 10K+ downloads, built using Unreal Engine 4.27. The game features realistic vehicle physics, an open-world city environment, mission-based gameplay, traffic simulation, car collection progression, and a full HUD with revs, gear, and speed. Developed under the studio name PUNEA — the architecture uses modular C++ plugins for vehicle physics and procedural environments, with complete game logic authored in Blueprint scripting. Features include ABS/TC/ESP simulation, realistic car damage, VFX, and a checkpoint mini-game mode.

Key Features
🧩
C++ Plugin Architecture
Modular C++ plugins for vehicle physics and procedural environments, exposed to Blueprint via UE4's reflection system (UFUNCTION, UPROPERTY) — mirroring professional studio workflows.
🔷
Full Blueprint Game Logic
Complete game logic authored in Blueprint — events, timelines, actor spawning, and touch-input controllers — keeping the gameplay layer fast to iterate without recompiling C++.
🌍
Procedural Environments
Runtime procedural world generation via C++ plugin, creating varied environments without baked-in level data — keeping APK size manageable on mobile.
📱
Mobile Optimization & Deployment
Memory-efficient asset streaming for stable frame rates across Android profiles, with custom touch-input handling and full Google Play Console deployment pipeline.
