Overview
A production-ready 3D vehicle simulator deployed on Android via Google Play Store, built using the professional Unreal Engine 4 workflow. The architecture separates concerns cleanly — modular C++ plugins handle vehicle physics and procedural environment generation, while complete game logic (events, timelines, actor spawning, touch-input handling) is authored in Blueprint scripting for fast iteration. Memory-efficient asset streaming keeps frame rates stable across a wide range of Android hardware.
Tech Stack
Unreal Engine 4.27 Blueprint Scripting C++ Plugin Development UE4 Reflection System Procedural Generation Vehicle Physics Android Optimization Google Play Pipeline Git · GitHub
Key Features
🧩
C++ Plugin Architecture
Modular C++ plugins for vehicle physics and procedural environments, exposed to Blueprint via UE4's reflection system (UFUNCTION, UPROPERTY) — mirroring professional studio workflows.
🔷
Full Blueprint Game Logic
Complete game logic authored in Blueprint — events, timelines, actor spawning, and touch-input controllers — keeping the gameplay layer fast to iterate without recompiling C++.
🌍
Procedural Environments
Runtime procedural world generation via C++ plugin, creating varied environments without baked-in level data — keeping APK size manageable on mobile.
📱
Mobile Optimization
Memory-efficient asset streaming to maintain stable frame rates across Android device profiles, with custom touch-input handling mapping gestures to vehicle controls.
🚀
Google Play Deployment
Full deployment pipeline — build packaging, APK signing, store listing, and release management through the Google Play Console.
